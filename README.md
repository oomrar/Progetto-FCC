# 🐍 My Python Journey (freeCodeCamp)

This repository contains my completed solutions, scripts, and certification projects for the **Scientific Computing with Python** program on [freeCodeCamp](https://www.freecodecamp.org/).

---

## 🚀 Key Topics Covered

Through this 300-hour hands-on curriculum, I gained proficiency in core programming concepts and algorithmic thinking using Python:

- **Python Basics & Syntax:** Variables, conditionals, loops, sequences, dictionaries, and sets.
- **Object-Oriented Programming (OOP):** Designing classes, methods, inheritance, and object interactions.
- **Data Structures & Algorithms:** Linear data structures, Hash Tables, and fundamental algorithms.
- **Error & Exception Handling:** Writing robust code with proper debugging techniques.
- **File & Data Manipulation:** Processing strings, data, and structured configurations.

---

## 🏆 Completed Certification Projects

As part of the certification requirement, I built 5 hands-on projects:

1. **User Configuration Manager**  
   *A script designed to handle, update, and manage structured configuration data.*
2. **Budget App**  
   *An object-oriented application to track expenses across categories, calculate spending percentages, and generate formatted text-based charts.*
3. **Polygon Area Calculator**  
   *A project utilizing OOP principles (classes and inheritance) with `Rectangle` and `Square` shapes to compute geometric dimensions and areas.*
4. **Hash Table Implementation**  
   *A custom data structure implementation focusing on key-value storage and collision handling.*
5. **Arithmetic Formatter / Core Algorithms**  
   *Algorithmic problems focused on string manipulation, formatting, and mathematical logic.*
